# Пример сайта для автоимпорта

Демонстрационный сайт для компании, которая привозит автомобили из Кореи, Японии и Китая.
Логотип, тексты, цены и фото в нём примерные: под каждого клиента всё заменяется.

Что внутри: сцены на прокрутке, каталог с фильтрами, расчёт стоимости, этапы сделки,
пример панели управления и форма заявки (в демо данные никуда не отправляются).

## Запуск у себя

```bash
npm install
npm run dev      # разработка, http://localhost:3000
npm run build    # статическая сборка в папку out
```

## Публикация

```bash
npm run deploy   # собирает сайт и выкладывает его в ветку gh-pages
```

GitHub Pages отдаёт ветку `gh-pages`. Адрес сайта и имя репозитория задаются в `scripts/deploy.mjs`.

## Источники фото

Фото автомобилей и городов взяты из открытых материалов Wikimedia Commons
(лицензии CC0 и CC BY), обработаны. Авторы перечислены в окне «Источники фото» внизу сайта.

Стек: Next.js 16, React 19, Tailwind CSS 4, Motion, Lenis, Radix UI.
